lending, foreign exchange, treasury management, tokenized assets, and agentic
commerce.

Arc uses USDC as its native gas currency, is EVM-compatible, and is designed to
provide fast, deterministic transaction finality for stablecoin-based financial
applications.

## About Arc

Arc is a stablecoin-native Layer-1 blockchain focused on financial applications
and global settlement.

### Key characteristics

- **USDC-native gas:** Transaction fees are paid in USDC.
- **EVM compatibility:** Ethereum-compatible smart contracts and tooling can be
  adapted for Arc.
- **Stablecoin-focused design:** Built for payments, settlement, lending,
  treasury, FX, and onchain markets.
- **Fast settlement:** Designed for sub-second blocks and deterministic finality.
- **Cross-chain connectivity:** USDC can move across supported networks through
  Circle infrastructure and CCTP.
- **Enterprise and developer focus:** Suitable for financial institutions,
  fintech applications, DeFi protocols, and agentic economic applications.
- **Open application layer:** Developers can deploy smart contracts and build
  applications on the network.

## Status Labels

Projects in this list may use the following status labels:

- **Mainnet:** Publicly available on Arc mainnet.
- **Testnet:** Available only on Arc testnet.
- **Beta:** Public application with incomplete or experimental features.
- **Early access:** Limited access, waitlist, or invitation required.
- **Unverified:** Listed by the community but not independently verified.
- **Inactive:** Website, deployment, or application may no longer be operational.

Project status can change quickly, especially around the Arc mainnet launch.
Check the project's official announcements and verify the connected network before
using an application.
